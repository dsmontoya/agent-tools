# Product Requirements Document: User Onboarding

## 1. Context

### 1.1 Background

Self-serve sign-up has been slow and confusing for new users.

## 2. Product Overview

The onboarding flow guides a new user from sign-up to their first successful action in the product. See [billing context](./billing.md#nonexistent-section) for related metrics.

## 3. Goals and Objectives

### 3.1 Business Goals

Increase first-week retention.

### 3.2 Objectives and Key Results (OKR)

Lift week-1 retention from 28% to 45% by end of Q3.

## 4. Core Concepts

A "session" is a single user-driven interaction with the onboarding flow.

## 5. Target Users

New self-serve users on the free plan.

## 6. Product Capabilities

The product walks the user through identity setup, workspace creation, and a guided first task.
